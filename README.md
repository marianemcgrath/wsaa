## Getting Started

### Clone the Repository

```bash
git clone https://github.com/marianemcgrath/wsaa.git
cd wsaa
```

### Pre-requisites

- **Python 3**
- **Requests** – for API calls
- **Git & GitHub** – version control

### Install Dependencies

```bash
pip install -r requirements.txt
```

## Inside the Folder

```
🔷 Assignment02-carddraw.py     →   A program that calls the Deck of Cards API to shuffle a deck, draw 5 cards for each player (2), display each card's value and suit,
                                    and then check the hand for special combinations like pairs, triples, straights, or a flush.

🔷 Assignment03-cso.ipynb       →   A program that locates the "Exchequer Account (Historical Series)" dataset on the CSO (Central Statistics Office) website, 
                                    fetches it via their API, and saves the raw JSON response directly to a file called cso.json

🔷 Assignment04-github.ipynb    →   A Python script that uses the GitHub API to fetch a file from a repository, replaces every instance of "Andrew" with "Mariane",
                                    then commits and pushes the updated file back to the same repository — with credentials stores securely in environment variables.
```
